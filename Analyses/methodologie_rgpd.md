# Methodologie

USER_ID est pseudonymisé mais reste une donnée personnelle ;
il est utilisé uniquement dans les couches de préparation ;
il est absent du mart final ;
les âges sont déjà regroupés en tranches ;
aucune donnée nominative, adresse ou adresse électronique n’est exportée ;
les résultats sont agrégés ;
les données INSEE sont publiques et agrégées ;
les transformations ne permettent pas d’identifier directement une personne ;
les populations utilisées sont celles de 2025 ;
les éventuelles populations nulles correspondent à une absence de correspondance fiable et ne sont pas remplacées artificiellement.
